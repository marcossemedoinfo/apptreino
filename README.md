# AppTreino 3D

Aplicativo web interativo baseado em HTML, CSS, JavaScript e Three.js para acompanhar treinos semanais na esteira, exercícios complementares e alongamentos em 3D com cronômetros individuais por etapa.

## Recursos

- **Personal Trainer 3D Humana Real (`SkinnedMesh` GLB)** com transições fluidas entre poses, curva natural de coluna/cabeça e respiração contínua.
- **Controles 3D completos**: rotação 360°, zoom, ângulos pré-definidos (`3/4`, `Frente`, `Lado`, `Topo`), giro automático, velocidade (`0.5x` / `1x` / `1.5x`) e destaque anatômico.
- **Cronômetro individual ao lado de cada treino, etapa da esteira e alongamento**, com controle de séries (`S1`, `S2`), repetições e lado (`Direito` / `Esquerdo`).
- **Progressão de 4 semanas da esteira** e ajuste de inclinação (`0%` a `1%`).
- **Salvamento automático local** (`localStorage`) e alertas sonoros via Web Audio API.

## Créditos
